# 补充说明

连接并读取首条反馈后，按需要查阅运行和迁移说明。这些规则在四款型号间复用；具体控制模式和参数单位仍以型号手册为准。

- [反馈新鲜度](../../FEEDBACK.md)：`get_feedback()` 的完整性、单调接收时间、缓存与采样时间的区别。读取缓存不保证获得新的设备反馈。
- [通信后端与故障恢复](../../TRANSPORT.md)：默认 CANTransport、可选 dispatcher、整组队列准入、背压、初始化失败及关闭重试。发送入队不等于设备完成运动。
- [迁移说明](../../MIGRATION.md)：独立 SDK 的包名、导入和依赖安装调整。
- [ROS2 接入](../../ROS2.md)：Humble 与 Jazzy 的 Python、Pinocchio 和数值库组合；不同发行版使用独立环境。

切换后端或从总线故障恢复时，先停止目标生产并关闭旧连接，再按应用流程检查状态、配置模式和使能。SDK 不自动重放故障前的运动。
